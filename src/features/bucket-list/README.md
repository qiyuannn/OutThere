# Bucket List

Own this page's implementation here. `screen.tsx` is the page entry point.
Add `components/`, `hooks/`, `services/`, and page-specific tests here as needed.
Use shared UI from `@/components`, theme helpers from `@/hooks`, and the shared
Supabase client from `@/lib/supabase`. Do not create a second auth client.

The route entry is `src/app/(tabs)/bucket-list/index.tsx`. Add new navigable screens
inside that route folder and keep their implementation in this feature folder.
Coordinate changes to the main tab navigator, auth providers, shared theme, or
shared database contracts with the team.
